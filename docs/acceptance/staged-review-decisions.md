# Решения при реализации поэтапного построения

База `skills/a9234b0`, ветка `feat/staged-cad-agent`. Фактические проверки:
[verification.md](../verification.md). Решения записаны в порядке принятия.

| Решение | Причина и граница |
|---|---|
| Соседний worktree вместо `.worktrees/` | Не требуется менять ignore-правила исходного checkout с чужими изменениями. Worktree сохраняется для ревью. |
| Временно исключить stdio-тесты при неизвестном исходе COM | Нельзя запускать второй MCP, пока прежний worker не вышел. Решение отменено после естественного выхода: финальный набор включает настоящий stdio. |
| Автоматические этапы для native-вызовов | Поддерживается существующий интерфейс без обязательного `stage_id`. Названия менее выразительны, служебные этапы входят в общий лимит 32. |
| Угловой `IDimension.GetType()==1` вместо прежнего 3 | Значение подтверждено установленным SW2025 `swDimensionParamType_e` и фаской 45°. Ошибка в предположении дала бы неверные единицы; регрессии и live-чтение покрывают эту версию. |
| Native-мутации не занимают запланированный Python-этап | Иначе создание документа преждевременно завершало этап профиля. Цена — дополнительные автоматические этапы в лимите; модель получает их ID. |
| Аналитическая подвижность вместо `GetRemainingDOFs` | Недокументированный метод нестабилен. Для двух тел проверяются реальные EntityParams, два здоровых сопряжения, закрепление и LockRotation. Это доказательство конкретной пары, без универсального решателя подвижности. |
| Сохранить игнорируемые журналы и тестовые CAD-файлы | Они нужны для воспроизведения и содержат зависимости сборок. Автоматическое удаление уничтожило бы часть результатов. Публичные JSON содержат отобранные доказательства и код. |
| Явное открытие закрепляет точный документ в сессии | OpenDoc6 не активирует уже загруженный документ. ActivateDoc3 выполняется один раз без модального перестроения; проверяются точный путь и COM-идентичность, затем два независимых чтения приложения. Цена — два вызова лимита. Внешнее переключение по-прежнему запрещает исполнение. |

Промежуточная привязка вновь созданного документа по заголовку заменена точной
привязкой объекта NewDocument внутри STA: SaveAs не разрывает сессию, одноимённая
подмена не принимается. Независимый обзор выявил этот риск; исправление проверено
регрессиями RED→GREEN. Отложенных мелких замечаний ревью нет.

Независимый обзор всей ветки выполнен до завершающей live-приёмки. Позднейшие
исправления, найденные при приёмке, проверены автором и регрессиями; повторного
независимого обзора этих исправлений не было. Ветка оставлена для ревью без merge.
