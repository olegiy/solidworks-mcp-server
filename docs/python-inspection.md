# Чтение габаритов тела и точек эскиза

Ошибка `GetBodies2.GetBoundingBox` в присланном коде вызвана неверным именем метода
тела. Для `IBody2` нужен `GetBodyBox`, возвращающий шесть чисел в метрах:
`[xmin, ymin, zmin, xmax, ymax, zmax]`. Это приблизительный ограничивающий ящик,
который может меняться после перестроения; он не доказывает точные размеры детали.

В этом же фрагменте были ещё две ошибки: `GetStartPoint2`/`GetEndPoint2` возвращают
объекты `ISketchPoint`, поэтому координаты читаются через `X`, `Y`, `Z`; имя эскиза
читается у `feature.Name`, а не у `sketch.GetName()`.

В `execute_python` уже доступен `GET(obj, name, *args)`: он учитывает, что pywin32
может представить COM-метод как свойство. Минимальные исправления:

```python
box_mm = [v * 1000 for v in GET(body, "GetBodyBox")]
start = GET(line, "GetStartPoint2")
start_mm = [start.X * 1000, start.Y * 1000, start.Z * 1000]
sketch_name = feature.Name
```

Полный пример только чтения передаётся модели в описании инструмента `execute_python`.
Он выбирает именно `Эскиз1`, обрабатывает отсутствие тел/сегментов и явно обозначает
нелинейные сегменты как неподдержанные. Координаты точек остаются в системе эскиза;
с bbox в системе модели их нельзя сравнивать без преобразования.

Проверено на установленной библиотеке типов SolidWorks 2025: у `IBody2` есть
`GetBodyBox` и нет `GetBoundingBox`; `GetStartPoint2`/`GetEndPoint2` возвращают
`VT_DISPATCH`, `ISketchPoint` содержит свойства `X/Y/Z`, у `ISketch` нет `GetName`.
Онлайн-страницы справки 2025 вернули HTTP 403; описание приблизительности bbox
дополнительно проверено через Context7 по [официальной справке](https://help.solidworks.com/2026/english/api/sldworksapi/SOLIDWORKS.Interop.sldworks~SOLIDWORKS.Interop.sldworks.IBody2~GetBodyBox.html).

Живое чтение исправленного примера через MCP прошло: одно тело, bbox
`[-2, -2, 0, 58, 38, 80]` мм, найден `Эскиз1`, прочитаны две линии с концами
`[0, 38, 0] → [0, 0, 0] → [58, 0, 0]` мм в системе эскиза. Геометрия и файлы
не изменялись. Локальный результат: `.superpowers/inspection-fix.json`.

Автоматических повторов после ошибки нет. Новый Python-код в чате по-прежнему
требует первого подтверждения для диалога и подключения; успешное чтение bbox не меняет
`execute_python` в инструмент независимой точной проверки геометрии.
