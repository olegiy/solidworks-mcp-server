## Независимый обзор

Выполнен независимый обзор всего нового репозитория относительно upstream и утверждённого
плана. Critical и Minor не обнаружены. Найдены пять Important; все исправлены с
наблюдавшимся переходом падающего регрессионного теста в успешный:

1. SDK пытался принудительно завершить MCP после двух секунд закрытия stdin, хотя
   COM мог продолжать работу. Для закреплённого SDK 1.30 задано неограниченное ожидание
   естественного выхода. Приложение сохраняет владение до выхода MCP. Команда stop
   после 180 секунд может сообщить, что остановка ещё идёт; принудительного kill нет.
2. DNS-имя `127.example.com` ошибочно считалось локальным. Теперь UI проверяет полный
   loopback IPv4 либо localhost/IPv6; внешнее подключение требует согласия.
3. Таймаут снимка терял признак неопределённости. Ошибка теперь структурирована;
   успешный снимок по-прежнему возвращается image-блоком.
4. Пути Windows с пробелами, запятыми/точками с запятой могли скрываться частично.
   Маскирование расширено с обратимым восстановлением; неоднозначный хвост пути
   к каталогу скрывается консервативно и может включить следующий текст.
5. Ошибка записи сведений после запуска могла оставить экземпляр без управления.
   Публикация теперь предшествует созданию дочернего процесса.
