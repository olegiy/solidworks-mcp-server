## 26 октября: Save с полной перепиской и Open

Кнопка «Сохранить проект» в шапке становится доступной после завершения
последнего прогона и вызывает `POST /api/cad/save` с `session_id`. Сервер напрямую сохраняет активный документ
через MCP и пишет рядом sidecar `<документ>.cadnext.json` с полными сообщениями,
снимками прогонов, языком, профилем и путём документа. Уже сохранённый документ
сохраняется на месте, новый — в «Документы» с расширением по типу и числовым
суффиксом. Новый Run не создаётся, лимит не расходуется. Кнопка «Открыть»
загружает sidecar через `POST /api/conversations/open`, проверяет схему, версию,
размер (64 МиБ), сообщения, события и завершённость прогонов, восстанавливает
историю и прогоны, а при совпадении ID создаёт копию. Загруженная переписка
переживает обновление страницы и продолжается с полным контекстом.

Проверены сохранение на месте, путь нового документа, sidecar, загрузка копии,
продолжение с прежней историей, битый файл, ошибка без активного документа и
результат в интерфейсе. Итог: Python 296 passed, 6 skipped, 2 deselected (живой
