# Фактические проверки

Дата: 25 октября 2026 года. Отдельный репозиторий `CAD-Agent-Next`, ветка
`work/minimal-app`. Публикация и слияние не выполнялись. Старый CAD-Agent не изменялся.

## Дополнение: сила рассуждения и одна кнопка каталога

Отдельная кнопка «Загрузить модели» удалена: открытие/повторная загрузка после ошибки
доступны через стрелку у поля. Добавлен сохраняемый в подключении `reasoning_effort`:
режим API по умолчанию и уровни `none`, `minimal`, `low`, `medium`, `high`, `xhigh`, `max`.
В режиме по умолчанию параметр в запрос не добавляется. Поддержка уровней конкретным
провайдером не определяется автоматически; переключения и повторов при отказе API нет.

Наблюдались 17 новых падающих Python-проверок и падение браузерного сценария на лишней
кнопке до реализации. После изменения весь набор: 178 тестов Python пройдены, 1 живой
пропущен по умолчанию; 12 браузерных сценариев пройдены, Ruff и сборка UI успешны.
Проверены восстановление уровня после нового чтения настроек, сохранение при частичном
обновлении, старый профиль без поля, некорректные значения, фактический исходящий JSON
провайдера/проверки подключения и повторный вход в UI. Независимый обзор замечаний не выявил.
Для общего прогона приложение без активного запроса штатно остановлено; после проверки
запущено вновь. Запросов к живому LLM или CAD для этого изменения не выполнялось.

## Дополнение: выбор модели из API

Добавлены автоматическая загрузка каталога при открытии поля «Имя модели», поиск
по части названия без учёта регистра, выбор мышью/клавиатурой и ручной ввод.
Загрузка работает до сохранения подключения и не записывает настройки. Сохранённый
ключ используется только при совпадении адреса API; смена адреса/ключа/подключения
сбрасывает каталог, старые ответы игнорируются.

После изменения: 161 тест Python пройден, 1 живой тест пропущен по умолчанию;
11 браузерных сценариев пройдены; Ruff и сборка TypeScript/Vite успешны.
Шесть новых API-проверок и браузерный сценарий сначала воспроизвели отсутствие
функциональности, затем прошли. Проверены также ошибка каталога, повторная загрузка
и запоздавший ответ. Независимый обзор изменений замечаний не выявил.

## Живой SolidWorks

В задаче 1 ранее подтверждено подключение к SolidWorks 2025, revision 33.5.0;
открытых документов тогда не было. Это не подтверждает создание геометрии.

Сначала SolidWorks отсутствовал, и smoke остановился на первом подключении без
следующих вызовов. Затем пользователь вручную запустил один экземпляр и подтвердил
готовность. На старте живой приёмки открытых документов не было. Пользовательские
документы не изменялись, SolidWorks автоматически не запускался.

## Независимый обзор

Выполнен независимый обзор всего нового репозитория относительно upstream и утверждённого
плана. Critical и Minor не обнаружены. Найдены пять Important; все исправлены с
наблюдавшимся переходом падающего регрессионного теста в успешный:

1. SDK пытался принудительно завершить MCP после двух секунд закрытия stdin, хотя
   COM мог продолжать работу. Для закреплённого SDK 1.30 задано неограниченное ожидание
   естественного выхода. Приложение сохраняет владение до выхода MCP. Команда stop
   после 180 секунд может сообщить, что остановка ещё идёт; принудительного kill нет.
2. DNS-имя `127.example.com` ошибочно считалось локальным. Теперь UI проверяет полный
   loopback IPv4 либо localhost/IPv6; внешнее подключение требует согласия.
3. Таймаут снимка терял признак неопределённости. Ошибка теперь структурирована;
   успешный снимок по-прежнему возвращается image-блоком.
4. Пути Windows с пробелами, запятыми/точками с запятой могли скрываться частично.
   Маскирование расширено с обратимым восстановлением; неоднозначный хвост пути
   к каталогу скрывается консервативно и может включить следующий текст.
5. Ошибка записи сведений после запуска могла оставить экземпляр без управления.
   Публикация теперь предшествует созданию дочернего процесса.

После исправлений общий набор, сборка, линт и браузерные сценарии повторно пройдены.
Дополнительная проверка автора обнаружила раннее освобождение порта Uvicorn перед
ожиданием MCP. Сохранён отдельный исходный сокет до полного выхода lifespan;
регрессионный тест воспроизвёл ошибку и прошёл после исправления.
На момент независимого обзора живого окружения не было. Геометрию автор проверил
после запуска SolidWorks пользователем, как описано выше. Сборки/сопряжения, LLM
и реальные записи Credential Manager обзором и последующей приёмкой не оценены.
