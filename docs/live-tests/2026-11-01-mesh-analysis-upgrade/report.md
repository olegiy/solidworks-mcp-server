## Поверхности

Настоящий worker с пределами 1 ГиБ / 60 с вернул каталог за 26.25 с.
Поиск имеет бюджет 25 с между гипотезами и явно завершился неполным.
Найдено 47 участков, пригодны 16. Осталось нераспознанными 21772 грани
площадью 12206.491420 мм². Альтернативная модель учитывается даже при
недостаточном охвате её собственных параметров: узкие конические полосы
не подтверждают уникальную сферу. Альтернатива должна также подтверждать
погрешность внутри всех используемых треугольников: сфера, проходящая
только через два кольца вершин цилиндра, не делает цилиндр неоднозначным.
Число найденных участков при исчерпании
временного бюджета зависит от производительности машины; ID каждого
участка определяется его контекстом и поддерживающими гранями.

Параметры, охват, остатки, границы погрешности фасеток, обусловленность,
исключения и причины непригодности каждого найденного участка приведены
в [численной сводке](numeric-summary.json). Нераспознанная геометрия
не удаляется из эталона и полностью участвует в сравнении.

## Проверка полного исходника

Сравнение исходной сетки с самой собой использует математическую фикстуру
с известными фасетками, нулевой погрешностью триангуляции и единичным
преобразованием. Это не проверка экспорта SolidWorks.

Метод `stratified_triangle_surface_v2` проверил по 50000 случайных точек
и все 28654 центроида в каждом направлении. Каждая сторона распределена
по 512 пространственным участкам; покрытие полное. Численный статус —
`pass`, выборочные максимумы 8.84×10⁻¹⁰ / 2.01×10⁻¹⁰ мм; время 13.83 с.
Измерение времени информационное, тесты от него не зависят.

Случайная выборка и центроиды не доказывают максимум Хаусдорфа.
Production `precision_known=false` сохранён. Ни этот отчёт, ни завершение
четырёх этапов не подтверждают точность ITessellation, направление
построения или готовность живой реконструкции держателя.
