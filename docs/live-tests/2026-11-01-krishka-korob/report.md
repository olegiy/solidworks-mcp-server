## Ошибки и исправления

1. Ошибка локального плана завершала Run даже при отсутствии CAD-изменений.
   Отклонённый план теперь возвращается модели с текущим допустимым состоянием;
   начатые этапы, история и ограничения остаются неизменными. Хвост пакета
   закрывается без исполнения, запрос расходует лимит, stop соблюдается.
2. Пропуск `mesh_inspect` в новом Run раньше завершал попытку. Теперь действие
   отклоняется до Python-разрешения/MCP/изменения ревизии; модель может сначала
   прочитать эталон. Автоматического повтора мутации нет.
3. Маскированный Windows-путь внутри Python-строки восстанавливался как исходный
   текст и давал `unicodeescape` на `C:\Users`. Восстановление теперь разбирает
   строковый литерал и экранирует его значение; outgoing Python-история маскируется
   по значениям литералов. Проверены кавычки, raw/triple-строки, хвостовой слеш,
   внедрение операторов, соседние литералы, комментарии, f-string и позиции строк.
   При review найдено и исправлено несовпадение `splitlines` с токенизатором.
4. В повторном аудите модель указала `stage_id` из прежнего Run. Локальный
   отказ до CAD снова завершил Run. Проверка теперь возвращает
   `invalid_construction_stage` с текущим планом до разрешения Python и MCP;
   завершённые этапы не исполняются повторно. Проверены обе петли, лимит и stop,
   прежнее продолжение repair сохранено. Четыре регрессии RED → GREEN,
   47 целевых тестов и независимое ревью прошли.

Отдельные ошибки построения исправлялись после инспекции в существующей детали.
`CreateCornerRectangle` добавляет равенство сторон квадрата: достаточно одного
управляющего размера, второй может стать справочным. `AddToDB=True` не запрещает
слияние совпадающих точек: внутренние углы совпали с центрами наружных дуг.
Исправление удалило только четыре внутренние линии и создало независимый контур
в стороне, затем переместило его размерами. Обе группы полностью определены;
сохранившийся справочный `D1@RimProfile` не заявляется управляющим.

## Границы проверки

После исправлений: полный `.venv\Scripts\python.exe -m pytest -q -m "not live"`
дал **873 passed, 1 deselected**, 174,97 с. Осталось прежнее предупреждение
Starlette/httpx. Ruff и `git diff --check` прошли. Независимое ревью локальных
отказов и privacy-исправления не оставило открытых замечаний. UI не менялся.
Сервер штатно запущен заново, sidecar импортирован вместе с проверенным исходником
через staged import: две исторические попытки сохранены, `mesh_missing=false`.

`precision_known=false` не изменяется. Выборочное численное сравнение с STL
не является сертификацией допуска CAD-триангуляции. Редактируемость подтверждается
нативными эскизами, операциями и управляющими размерами, а не импортом фасеток.
Итог `mesh_compare` остаётся `unknown`: `cad_checks_unconfirmed` и
`unknown_or_insufficient_cad_precision`. `Run.status=completed` не означает
`verification=verified`; результат численно близок эталону, но допуск0,1 мм
по всей поверхности автоматически не сертифицирован. Проверки не ослаблялись.
