# План реализации CAD-Agent-Next

> Для исполнителя: выполнять последовательно через `executing-plans`, проверять поведение через `test-driven-development`. Отмечать завершённые шаги. Разработка уже разрешена пользователем 25 октября 2026 года; повторное согласование способа исполнения не требуется.

**Цель:** самостоятельное локальное приложение с собственным чатом, выбором модели и SolidWorks MCP на основе выбранного внешнего проекта.

**Архитектура:** FastAPI обслуживает React-интерфейс и последовательный агентский цикл. Отдельный Python MCP-процесс управляет единственным запущенным экземпляром SolidWorks через STA. Каталог инструментов извлекается через MCP SDK.

**Стек:** Windows, Python 3.12, MCP Python SDK, pywin32, Pillow, FastAPI, httpx, keyring, React 19, TypeScript, Vite, pytest, Playwright.

**Спецификация:** `docs/superpowers/specs/2026-10-25-cad-agent-next-design.md` (утверждена пользователем).

## Общие ограничения

- Новый самостоятельный репозиторий: `C:\Users\olegiy\CAD-Agent-Next`. Старые исходники и данные не изменять.
- Основа: `aiforyouself/solidworks-mcp-server`, коммит `2ad21ce7581111d55dcc85db9de32f7366d201f7`, 27 инструментов, MIT-уведомление сохраняется.
- Python 3.12+, React/TypeScript/Vite, loopback `127.0.0.1:8876`.
- Один активный CAD-запрос и один MCP-процесс, все COM-операции в единственном STA.
- Лимит по умолчанию — 80 инструментальных вызовов, включая проверки.
- CAD-ошибки завершают прогон; таймаут сохраняет неопределённость, автоматические повторы мутаций и undo запрещены.
- Секреты только Windows Credential Manager, namespace `cad_agent_next`; отдельный каталог данных `%LOCALAPPDATA%\cad_agent_next`.
- Документы и UI на русском; идентификаторы, тесты и комментарии кода на английском.

## Особое внимание при проверке

1. Вложенный `{status: error}` при внешнем успешном MCP-ответе должен остановить прогон (задачи 1, 3).
2. Разрыв браузерного соединения и остановка во время COM запрещают следующий вызов, сохраняя статус текущего (задачи 3, 4).
3. Несколько tool calls в одном ответе модели исполняются последовательно; каждый результат имеет правильный ID (задача 3).
4. Переход на внешний провайдер не обходит согласие и фильтрацию данных, включая изображения (задачи 2, 3).
5. Обновление страницы, повторный запуск приложения и занятый порт не создают второй CAD-запрос (задачи 4, 5).

## Файлы и ответственность

- `solidworks_mcp_server.py`: адаптированная MCP-основа и COM-инструменты.
- `cadnext/mcp.py`: официальный MCP-клиент, каталог, нормализация результатов.
- `cadnext/settings.py`: профили подключений, атомарный JSON, системное хранилище ключей.
- `cadnext/provider.py`: OpenAI-совместимые сообщения, tool calling, изображения, ошибки.
- `cadnext/privacy.py`: согласие и фильтрация исходящих данных, обратное восстановление локальных путей.
- `cadnext/agent.py`: один последовательный цикл, состояния прогона, подтверждение кода, остановка, проверки.
- `cadnext/app.py`, `cadnext/__main__.py`: локальное API, события, запуск и штатная остановка.
- `ui/src/App.tsx`, `api.ts`, `styles.css`: чат, подключения, события, снимки, подтверждения.
- `tests/`: автономные регрессии, настоящий stdio smoke, отдельный живой smoke.
- `scripts/setup.ps1`, `scripts/start.ps1`, `scripts/stop.ps1` и bat-обёртки: воспроизводимый запуск.
- `README.md`, `UPSTREAM.md`, `docs/verification.md`: запуск, происхождение и фактические результаты проверок.
