# Улучшение mesh-анализа: план исполнения

Основание — согласованные пользователем четыре плана от 01.11.2026.
Исполнение: последовательно, TDD, отдельный коммит после каждого плана.

## Общие ограничения

Собственная MIT-реализация на существующих зависимостях. Вход STL/OBJ до
100 МиБ и 250000 граней/вершин. Worker: 1 ГиБ, 60 с, IPC 1 МиБ;
сводка модели 64000 байт. Без repair, ICP и изменения единиц наугад.
COM/ITessellation и живое построение SolidWorks в эту работу не входят.
Production precision_known=false сохраняется.

## Задача 1: подготовленная сетка и транспорт

- [x] Неизменяемый PreparedMesh, повторное использование геометрии и связности.
- [x] Кеш одного эталона с владельцем, путём, SHA256, форматом, единицами,
  преобразованием, кадром и версией. Проверка байтов при каждом запросе.
- [x] Инвалидация при удалении/замене/закрытии, сохранение исправного worker
  после empty_region/disconnected_region.
- [x] Части JSON по 512 КиБ до base64, полная проверка размера/порядка/SHA256,
  общий deadline и lock; полный результат до 64 МиБ. Без усечения доказательств.
- [x] RED/GREEN: кеш, смена контекста, большие ответы, повреждённые части,
  stop/timeout/restart; численный замер холодного и повторного запросов.

## Задача 2: аналитические поверхности

- [x] Каталог surfaces с пагинацией100, сохранение regions по умолчанию.
- [x] Выбор mesh_fit через surface_id или seed_mm с bounds/axis/side;
  старые region_id/all/целые треугольники в bounds сохраняются.
- [x] Plane/cylinder/cone/sphere/torus: устойчивая оценка, grow/refit,
  конкурирующие гипотезы, неоднозначность и нераспознанный остаток.
- [x] Новые выборки: максимум2% исключённых точек и5% площади с явными
  метриками; связность обязательна. Проверка внутренностей граней <=T/4.
- [x] Минимальный охват: цилиндр30°, конус60°, сфера60° в двух направлениях,
  тор90° по двум кругам; конус: высота и изменение радиуса >2T;
  кольцевой тор R>r>0; нормированная обусловленность <=1e8.
- [x] RED/GREEN: чистые/шумовые примитивы, соседние поверхности, малые дуги,
  грубые фасетки, неидентифицируемость, детерминизм, старые интерфейсы.
  Шум sigma=T/20;1% выбросов со смещениемT; общие вершины сохраняются.

## Задача 3: сечения

- [x] Топологические ключи рёбер/вершин без склейки разных краёв по расстоянию.
- [x] Копланарные грани, outer/hole, открытые/ветвящиеся/пересекающиеся цепочки.
- [x] Смешанные линии/дуги с общими концами и двусторонней ошибкой <=T/4,
  полный круг — две дуги; без автоматического замыкания.
- [x] ID связаны с исходником/кадром/плоскостью/T/версией; полный provenance.
- [x] RED/GREEN: касания, грани/вершины/рёбра, отверстия, скруглённый профиль,
  малый разрыв при большомT, преобразования и большие ответы.

## Задача 4: сравнение v2

- [x] stratified_triangle_surface_v2:50000 точек по площади на сторону плюс
  центроид каждой грани. До512 пространственных участков на сторону;
  распределение по медиане наибольшего размера, tie-break по ID грани.
- [x] Все грани участвуют; неполнота/ресурсный предел означают unknown.
- [x] mesh_region_ids этапов: до128 уникальных ID на Run; неизменяемость

- [x] Независимый evidence gate v1/v2, актуальность источника/документа/Run;
  исторический импорт unknown, полные доказательства локально.
- [x] UI/SSE: покрытие и причины неполноты, сохранение/open/replay.
- [x] RED/GREEN: ретриангуляция, маленькое отверстие при >99% совпадения,
  лишнее/недостающее, тысячи старых областей, обязательные ID, stop/stale.

## Финальная проверка

Полный non-live pytest, Ruff, сборка UI и Playwright. Численный read-only
отчёт по исходнику держателя. Независимый обзор всей работы и исправление
существенных замечаний через RED/GREEN. Успех численной подсистемы не
означает готовность живой реконструкции SolidWorks.
