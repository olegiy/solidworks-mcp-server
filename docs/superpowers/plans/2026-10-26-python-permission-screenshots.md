# Постоянное разрешение Python и полный кадр SolidWorks

Требования пользователя: сохранять разрешение Python постоянно и центрировать модель перед снимком.

Решение: общее разрешение приложения хранится в `settings.json`, сохраняется атомарно
и действует для любых диалогов/подключений после перезапуска. Первое подтверждение
включает постоянное разрешение; в настройках его можно включить и отозвать. Текущий
запрос пользователя разрешает включить настройку в рабочем приложении при обновлении.
Без разрешения выполняющийся код не запускается; ошибка записи разрешения останавливает запрос.

Снимок всегда подгоняет текущий вид через `ViewZoomtofit2`, затем перерисовывает окно.
Команды представления поддерживают COM-метод и свойство без повторного вызова.
`SaveBMP(..., 0, 0)` сохраняет весь текущий вид; Pillow пропорционально уменьшает
изображение до заданных размеров без обрезки. Ориентация сохраняется, если явно
не запрошена изометрия. Всё выполняется внутри существующего STA-вызова.
