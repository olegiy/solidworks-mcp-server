# Исправления по живому тесту крышки

**Цель:** построить редактируемую крышку по `krishka_korob.STL` через приложение и SolidWorks, исправляя воспроизведённые ошибки кода.

**Решение:** сохранить строгие проверки CAD и неизменяемость начатых этапов. Отклонённые до исполнения локальные запросы возвращать модели с конкретной причиной и текущим допустимым состоянием; оставшийся пакет не исполнять. Каждый новый запрос учитывается в лимите, автоматического повтора нет. Ошибки CAD и неизвестный исход остаются терминальными по существующим правилам.

Работа выполняется в текущей ветке `feat/mesh-to-cad`: сервер запускается из этого каталога, отдельное рабочее дерево потребовало бы второго окружения и экземпляра приложения. Пользователь разрешил исправления и повторные живые прогоны до готовой модели.
