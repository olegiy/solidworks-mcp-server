# Предотвращение ошибок построения

Источник — четыре снимка прогонов из работающего локального API, прочитанные
28.10.2026. Последний прогон чертежа завершился HTTP 522. Среди известных ошибок:
`SelectByID2(..., None, ...)`, отсутствующее `DraftAngle`, импорт `requests`,
переменная `tl` из другого вызова. Без исключений прошли неверный порядок точек
`Create3PointArc` и размер 170 мм при требуемых 200 мм из-за индексов 0/1.

Исправление: до доступа к SolidWorks разбирать Python и отклонять известные
неверные литеральные аргументы `SelectByID2` и `Get/SetArcEndCondition`, включая
форму `GET`. Сохранять номер строки и явный признак предварительной проверки.
Динамические значения не угадывать, код не переписывать и не выполнять повторно.
Дополнить описание Python-инструмента и инструкции агента проверенными правилами
API, независимостью окружений и обязательной числовой сверкой с исходным чертежом.

Одни подсказки дешевле, но не блокируют известные неверные вызовы. Полная проверка
COM-типов произвольного Python потребовала бы существенно другого исполнителя.
Выбрана узкая предварительная проверка и инструкции для семантики геометрии.

Каталог остаётся из 27 инструментов, механизм разрешений и STA не меняются.
Текущие документы, процессы приложения и ключи не изменяются. HTTP 522 нельзя
устранить в CAD-коде; автоматических повторов не добавляется. Инструкции уменьшают
риск новых ошибок модели, но не доказывают соответствие всей геометрии.
