# Динамические уровни рассуждения OpenRouter

## Цель

Показывать в настройках и нижней панели чата опубликованные OpenRouter уровни рассуждения выбранной модели, включая подключения к другим API. Выбор сохраняется в профиле; поддержка параметра сторонним API зависит от этого API.

## Объём

- Для OpenRouter читать `reasoning.supported_efforts`, `reasoning.default_effort` и `reasoning.mandatory` из каталога `/api/v1/models`.
- Передавать в UI нормализованный список `{value, label}` и признак обязательности рассуждения.
- Сбрасывать устаревший выбор при смене модели, если новый каталог его не поддерживает.
- Хранить выбранный уровень в существующем профиле подключения; текущая модель профиля остаётся ключом настройки.
- Для других адресов получать метаданные из публичного каталога OpenRouter без ключа. Сопоставлять точный ID либо уникальное имя без префикса, не угадывая суффиксы и псевдонимы.
- При отсутствии совпадения или метаданных сохранять текущий список уровней и вариант «По умолчанию API», показывая причину.

## Ограничения и безопасность

- Имена моделей загружаются у выбранного подключения. Независимый публичный каталог уровней загружается с фиксированного адреса OpenRouter без ключей, имён выбранных моделей и содержимого чата; сопоставление выполняется локально.
- Каталог не используется для пробных платных запросов.
- Неизвестные поля каталога игнорируются; сетевые ошибки оставляют ручной выбор.
- Значения из каталога валидируются на backend и UI, чтобы не передавать произвольные параметры.

## Подходы

1. OpenRouter-first: использовать официальные метаданные OpenRouter и fallback для остальных API. Выбранный вариант: минимальный охват с точными данными и без риска для локальных подключений.
2. Универсальные адаптеры для нескольких провайдеров: шире охват, но разные схемы и больше зависимость от нестабильных API.
3. Пробные запросы: не подходит из-за стоимости, задержки и побочных ошибок.

## Проверка

Добавляются backend-тесты каталога и нормализации, UI-тесты выбора уровней OpenRouter, fallback, смены модели и сохранения значения. После этого запускаются полный pytest, Playwright, UI build, Ruff и `git diff --check`.
