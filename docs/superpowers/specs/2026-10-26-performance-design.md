# Ускорение CAD-Agent Next

Пользователь утвердил реализацию 26.10.2026. Цель — сократить время до готовой
и проверенной CAD-задачи во всех сценариях, сохранив проверки и правила COM.

## Решения

- Подсказывать модели объединение действий с известными аргументами в native
  tool calls одного ответа. Снимки нужны на границах этапов и по запросу,
  а числовые изменения сначала подтверждаются readback.
- `Provider.complete` получает полную локальную историю и строит отдельную
  детерминированную проекцию перед фильтрацией `PrivacyContext`. Локальные
  сообщения, изображения и свидетельства проверки сохраняются полностью.
- Только изображения, помеченные приложением как CAD-снимки, вытесняются
  более новым набором видов. Исходные пользовательские чертежи сохраняются.
  Повторяющиеся деревья заменяются точными дельтами с сохранением порядка,
  ошибок, единиц, размеров и статусов проверки.
- Обрезать только полностью белые/прозрачные внешние поля пользовательского
  изображения с небольшим отступом. Модель получает производную без изменения
  масштаба; принятый оригинал хранится локально. Если файл не стал меньше,
  отправлять исходный. CAD-снимки остаются в пределах 400×300.
- Добавить числовые метрики времени, тела запроса, изображений и usage API.
  Они не содержат запросов, кода, путей или секретов; отсутствующий usage — null.
- SSE передаёт событие и компактное состояние прогона. UI применяет их по seq,
  получает snapshot при открытии/восстановлении и наблюдаемый heartbeat.
- Экспериментальный провайдер поддерживает stream=true с накоплением и полной
  проверкой ответа. Обычный complete остаётся непотоковым. Бенчмарк сравнивает
  одинаковые запросы без выполнения CAD.
- Прототип независимой подготовки анализирует несколько изображений без tools,
  максимум два LLM-запроса одновременно вместе с основным. Он запускается явно
  в бенчмарке; обычные задачи не получают дополнительных платных запросов.
  Результат привязан к хешу входа, остановка отменяет только подготовку.

## Ограничения и приёмка

Один активный Run, один STA COM, 27 MCP-инструментов, прежние лимиты вызовов,
readback и поведение uncertain. Никаких автоматических повторов или undo.
Новые API-поля аддитивны. Компрессия не меняет локальную историю и служебные
поля native tools. Метрики и бенчмарки различают отсутствие данных и ноль.

Сравнение охватывает новую листовую деталь, изменение размеров, сборку,
Python и длинный диалог. Публикуются медиана/p90, число запросов, байты,
изображения, usage и проверенный результат. Фиктивные измерения не объявляются
измерениями живой модели или SolidWorks.
