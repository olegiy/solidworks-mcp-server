# Изображения в чате

Выбор подключения с моделью и силы рассуждения находится внизу, рядом с отправкой.
Подключение запоминается в браузере, сила рассуждения — в настройках выбранного
подключения. Нижний переключатель сохраняет её сразу; доступные уровни зависят от API.

Для модели, принимающей изображения, включите «Поддержка изображений» в настройках
подключения. Скрепка открывает выбор PNG, JPEG и WebP. Перед отправкой можно посмотреть
миниатюру и удалить файл. Допускается отправка изображений без текста.

Ограничения: до трёх файлов, до 2 МиБ на файл и до 4 МиБ суммарно; до 16 млн пикселей
и до 8192 пикселей по стороне. Ограничения размера действуют также после обработки.
Сервер проверяет содержимое и MIME-тип; повреждённые и анимированные изображения,
SVG и другие типы файлов не принимаются. Перекодирование удаляет метаданные,
предварительно применяя EXIF-ориентацию. Изображения не записываются на диск.

Картинки передаются выбранному API как изображения. Имена файлов провайдеру не
отправляются. Текст внутри картинки не маскируется. Признак поддержки изображений
задаётся пользователем: некоторые каталоги API не сообщают возможности модели.

Проверки: Python-тесты охватывают фактический исходящий запрос Provider, историю,
маскирование текста, ограничения, метаданные и ориентацию. Браузерные тесты проверяют
выбор через скрепку, предпросмотр, удаление, отправку нескольких изображений без
текста, восстановление истории, ошибки и запрет для текстового подключения.
HTTP-провайдер и CAD в этих тестах заменены фикстурами; живая vision-модель не проверялась.
