# AGENTS.md

## Проект и работа с контекстом

- CAD-Agent-Next — самостоятельное локальное приложение для SolidWorks: Python/MCP/FastAPI в `cadnext/`, React/TypeScript в `ui/`. Не импортируй `cad_agent` и не изменяй старый CAD-Agent. Сохраняй MIT и происхождение upstream в `UPSTREAM.md`.
- Начинай с `git status --short`, затем ищи через `rg` в каталогах текущей задачи. Не перезаписывай чужие незавершённые изменения.
- Не читай рекурсивно весь репозиторий. По умолчанию не открывай зависимости, сборки, кэши, отчёты, бинарные CAD-файлы и локальные данные: `.venv/`, `node_modules/`, `dist/`, `build/`, `__pycache__/`, `.pytest_cache/`, `.ruff_cache/`, `test-results/`, `playwright-report/`, `.superpowers/`. Читай их только при необходимости для задачи.
- Не используй `rg --no-ignore`/`--hidden` для общего поиска без необходимости. Lock-файлы открывай только для задач зависимостей; не редактируй их как способ сократить контекст. `.gitignore` помогает поиску, но не запрещает прямое чтение.
- Читай документы только по задаче: запуск — `README.md`; агент/проверки/Python-разрешения — `docs/agent.md`; API/SSE/UI — `docs/app.md`; провайдер/приватность — `docs/models-and-privacy.md`; вложения — `docs/image-attachments.md`; производительность — `docs/performance.md`; Python/COM — `docs/python-inspection.md`; журнал UI — `docs/activity-indicator.md`.
- Базовая архитектура: `docs/superpowers/specs/2026-10-25-cad-agent-next-design.md`, `docs/superpowers/plans/2026-10-25-cad-agent-next-implementation.md`; дополнения читай по задаче. Результаты и границы проверок — `docs/verification.md`; локальный прогресс — `.superpowers/progress.md`. Не дублируй здесь историю выполнения и числа тестов.

## Команды и проверки

- Windows, Python 3.12.10, Node.js 22.12+. Python запускай только через `.venv\Scripts\python.exe` (включая pytest: stdio-тесту нужен `mcp` из venv). Зависимости — `requirements.lock.txt`; `requirements.txt` — только upstream MCP.
- Python без CAD: `.venv\Scripts\python.exe -m pytest -q -m "not live"`; полный набор: `.venv\Scripts\python.exe -m pytest -q`. Live read-only включается только с `CADNEXT_LIVE=1`.
- Линт: `.venv\Scripts\python.exe -m ruff check .`; исключённый `solidworks_mcp_server.py` проверяй вручную. Mypy нет.
- UI, из `ui/`: `npm ci` при установке/смене зависимостей, `npm run build`, `npx playwright test`. Нужны свежая сборка и Chromium (`npx playwright install chromium`). Тесты запускают настоящий API/агент с фиктивными LLM/CAD на 8877, без ключей и SolidWorks.
- Для кода используй TDD и проверки по изменённому поведению. Для документации и ignore-правил достаточно проверки ссылок, `git check-ignore` и `git diff --check`; не запускай ради них CAD или API-бенчмарки.

## Запуск и владение процессами

- Установка/сборка: `setup.bat` (`-WithBrowser` добавляет Chromium). Запуск: `start.bat` (`-NoBrowser`), остановка своего фонового экземпляра: `stop.bat`; реализация — `scripts/*.ps1`.
- Ручной запуск после сборки UI: `$env:PYTHONUTF8=1`, затем `.venv\Scripts\python.exe -m cadnext`; адрес `http://127.0.0.1:8876`, остановка Ctrl+C. Только loopback; порт резервируется до MCP. Отдельный stdio-сервер: `.venv\Scripts\python.exe solidworks_mcp_server.py`.
- Владение экземпляром — случайные события Windows, mutex и runtime JSON, публикуемый до старта подпроцесса. Запрещены `taskkill`/`Stop-Process` по имени, порту или PID. `stop.bat` не управляет ручным запуском; детали — `docs/app.md`, `cadnext/launcher.py`.
- Остановка ждёт исхода начатого COM и естественного выхода MCP без ограничения. Не возвращай принудительное завершение из MCP SDK (по умолчанию 2 с после закрытия stdin), не запускай второй MCP и не освобождай владение раньше выхода первого.
- MCP получает только `PYTHONUTF8=1`, `SW_MCP_CALL_LOG=off`, `LOCALAPPDATA`; cwd — корень. Данные — `%LOCALAPPDATA%\cad_agent_next`, логи — `logs/`. Журнал вызовов выключен; включение — `SW_MCP_CALL_LOG=<путь>`.

## Инварианты CAD/MCP

- Любой COM-вызов — только через `com_call`: один STA (`ThreadPoolExecutor(max_workers=1)`), сериализация `_submit_lock`. Никакого COM из async, других потоков или параллельных вызовов.
- `COM_TIMEOUT=55` с; таймаут выставляет `_poisoned`, дальнейшие вызовы дают `ComOutcomeUnknown` до перезапуска. Не сбрасывай флаг, не повторяй операцию и не продолжай после неизвестного исхода.
- `_app()` подключается только к уже запущенному единственному `sldworks.exe`, сверяет `GetProcessID` при каждом обращении. Автозапуск и переключение экземпляра запрещены.
- Без fallback-цепочек мутаций: не повторяй неудачный `save_document` другим методом. `_run()` возвращает ошибки `CAD_ERROR`/`CAD_OPERATION_UNCERTAIN`; вложенный `{status:"error"}` — ошибка даже без MCP `isError`.
- `cadnext/mcp.py`: `{ok, value, images, error, uncertain}`, неопределённость сохраняется до перезапуска. Изображения — только MCP image-блоки. Контракт: 34 инструмента MCP, включая два скрытых служебных инструмента Python-сессий; модель получает 33 с локальным планом. Изменение каталога требует обновления `tests/test_mcp.py`. Поэтапное исполнение — `docs/staged-construction.md`.
- `screenshot` всегда подгоняет/перерисовывает вид в STA, возвращает `Image`, пропорционально уменьшается без обрезки до 400×300 по умолчанию. `zoom_to_fit=False` не отключает подгонку. COM-свойства/методы поддерживай без повторов.
- Внешние единицы — мм/градусы, COM — метры/радианы. Углы (`GetType()==3`) преобразуй через `math.radians`/`degrees`, не `_mm`. Плоскости локализованы: по умолчанию `Спереди`, для английской установки — `Front Plane`.
- `scripts.live_smoke` запускай модулем: без флагов чтение; `--mutate-new-part` — только новая тестовая деталь/временные файлы. При ошибке/неопределённости остановись. В SW2025 глубина `D2@<SMBaseFlange>`: прочитай 50 мм → измени до 62 → перечитай; не угадывай `D1@SheetMetal`.

## Агент, данные и язык

- Один активный Run, синхронно резервируемый `Agent.start`. Используй `wait`, `stop`, `aclose`; не отменяй `run._task` или начатый CAD при отмене ожидания.
- Сохраняй возрастающий `seq`, snapshot/replay, `Last-Event-ID`, SSE `update`, stop по `request_id` ещё до ответа POST. Разрыв SSE, закрытие генератора и `pagehide` запрещают следующие шаги, но ждут отправленный COM; детали — `docs/app.md`.
- Проверки входят в лимит (по умолчанию 80) и резервируются до мутации. `Run.verification` независимо от `status`: завершение может быть `unverified`. Без автоповторов; исключение — до двух исправлений известного Python `CAD_ERROR` с инспекцией/минимальным продолжением, без повтора прежнего кода (`docs/agent.md`). Неизвестный исход блокирует прогоны до перезапуска.
- Кнопка Save в шапке становится доступной после завершённого прогона и вызывает `POST /api/cad/save` с `session_id`: прямой `save_document` активного документа без нового Run и без расхода лимита. Уже сохранённый документ сохраняется на месте, новый — в «Документы» с суффиксом при совпадении имени. Рядом пишется sidecar `<документ>.cadnext.json` с полными `messages`, снимками прогонов, языком и путём документа. Кнопка «Открыть» загружает sidecar через `POST /api/conversations/open`, проверяет схему/размер/завершённость и восстанавливает `_history` и прогоны для продолжения; при совпадении ID создаётся копия с новым ID. Неизвестный исход сохранения блокирует новые прогоны.
- `Profile` неизменяем. `Provider.complete` получает исходную историю и сам применяет `PrivacyContext`, сохраняя native tool поля; перед MCP восстанови аргументы тем же `PrivacyContext.restore`. Смена API/модели требует нового контекста. Полную локальную историю и доказательства не сокращай ради исходящего контекста.
- Agent разрешает передачу выбранному API при старте без отдельного согласия; изображения — только с `vision`. Маскирование внешних текстов сохраняется, изображения не обезличиваются. Секреты — только Windows Credential Manager (`cad_agent_next`), никогда в JSON-настройках, ответах API или логах.
- `SettingsStore.python_execution_allowed` — общее постоянное разрешение, атомарно записываемое до выполнения; отзывается в настройках. Ошибка записи, отказ/stop, устаревший ID не разрешают код. Без SettingsStore — разрешение в памяти для пары диалог+профиль.
- UI/ответы — русский/английский (`navigator.language`, переключатель, `Accept-Language`, `language` запуска). Идентификаторы/тесты/новые комментарии в `cadnext/` — английские; русские комментарии upstream сохраняй. Документы — по-русски, если не запрошено иначе.
